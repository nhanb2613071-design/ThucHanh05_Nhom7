# ThucHanh05_Nhom7

## Mô tả nội dung thực hành
Đây là repository lưu trữ các file kết quả của Bài Thực hành 05: Tạo và Quản lý Mã Nguồn do Nhóm 7 thực hiện. Bài thực hành tập trung vào việc ứng dụng AI trong tạo nội dung đa phương tiện, phát triển mã nguồn web cơ bản và quản lý phiên bản sử dụng Git/GitHub.

## Cấu trúc thư mục và Danh sách file
Repository được tổ chức thành các thư mục tương ứng với từng phần của bài thực hành:
* **phần 1/**: Chứa file Báo cáo văn bản (PDF).
* **phần 2/**: Chứa các file đa phương tiện bao gồm Infographic (file PNG) và Video (file MP4 hoặc Link Google Drive).
* **phan3/**: Chứa file mã nguồn HTML (`index.html`) dùng để hiển thị nội dung infographic và video, cùng với các ảnh chụp màn hình minh chứng quá trình làm việc trên Google Docs, Canva/CapCut.

## Trích dẫn nguồn AI
Quá trình thực hiện bài tập có sự hỗ trợ của các công cụ Trí tuệ Nhân tạo:
* **Canva AI / CapCut**: Hỗ trợ thiết kế, tối ưu hóa bố cục và tạo lập hình ảnh cho Infographic và Video.
* **GitHub Copilot**: Hỗ trợ sinh mã nguồn HTML để nhúng đa phương tiện. Prompt đã sử dụng: *"Viết code HTML hiển thị một infographic và video MP4 trên trang web."*
